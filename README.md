## 🤖 What SPARK Is

**SPARK is a platform, not a one-time robot.** That is the whole idea.

Rather than solving a single problem, it runs a shared AI pipeline — **vision →
decision-making → feedback** — that can be reused across different robots and different
real-world scenarios. A camera observes the environment, AI models interpret what they
see, defined logic decides what to do, and the robot answers with movement, lights, speech
and on-screen feedback.

New ideas grow from the same core system. That is what makes it a platform.

## 👁️ Teaching a Computer to See

SPARK's eyes are a **custom YOLO object detection model trained from scratch** — not an
off-the-shelf one. 100 training runs, taking it from a **58.5%** score to **99.5%**, an
improvement of 41 points.

The full report explains the data labelling, the training, and the results, with graphs,
in language a fourth grader can read — because one wrote it.

📖 [**Dive into the Custom YOLO Model Report →**](https://saanvipagadala.github.io/spark-robotics/custom-yolo-model/)
